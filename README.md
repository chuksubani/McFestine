# McFestine

**A modern food-service and hospitality web application built with React.**

McFestine is a frontend application exploring a more convenient and accessible digital experience for food-service businesses and their customers.

The project was initiated and owned by Chukwuma Onuoha Ubani as a proposed digital solution for a business. I led its frontend implementation, coordinating contributions from other frontend developers and overseeing the development of the shared application.

## Features

The application includes the following interface areas:

- **Homepage:** A customer-facing landing experience.
- **About:** Business information and service presentation.
- **Contact:** Contact information and customer enquiry interface.
- **Authentication:** Sign-in and registration interfaces.
- **Service presentation:** Interfaces showcasing offerings such as reservations, order tracking, custom lists and food services.

## Technology Stack

- React 18
- JavaScript (ES6+)
- Vite

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/chuksubani/McFestine.git
```

Navigate into the project:

```bash
cd McFestine
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Creates a production build |
| `npm run lint` | Runs ESLint |
| `npm run preview` | Previews the production build |
